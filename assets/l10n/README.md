# مستكشف الوقف — حزمة الترجمة (JSON)

هذه الحزمة تحتوي على قاموس الترجمة الرسمي لمستكشف الوقف (ar/en) بصيغة JSON.

## الملفات
- `ar.json` العربية (RTL)
- `en.json` الإنجليزية
- `l10n_keys.txt` قائمة مفاتيح (مرتبة)

## ملاحظات
- أسلوب المفاتيح: Namespaces بالنقطة (مثل `admin.homeManagement.title`) لتجميعها حسب الميزة.
- القيم قد تتضمن Placeholders مثل `{count}` أو `{value}`.
- يجب أن تتطابق المفاتيح بين `ar.json` و `en.json` 100%.
- عدد المفاتيح: **796**.

## النطاق
مغطي لواجهات:
- بوابة الجمهور + صفحة الخريطة
- لوحة التحكم (Admin) + إدارة الطبقات + الاستثمار + RBAC
- التقارير/التدقيق/النسخ الاحتياطي + الإشعارات + المساعدة
